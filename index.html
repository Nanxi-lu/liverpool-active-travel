Single-file progress summary of the current dissertation data analysis, organised by workflow stage. It labels what each section does, what outputs exist, and how the findings should currently be interpreted.

0. Overall Position

The current work has built a descriptive and exploratory evidence base for assessing active-travel scheme areas using Vivacity countline data, supported by spatial context, matched control candidate mapping, and supplementary rail station time-series context.

Current conclusion in one sentence: the analysis prepares quality-checked Vivacity active-travel outputs, separates pedestrian/cyclist and road/path outcomes, compares before/after peak averages where usable baselines exist, and uses maps plus rail trends as supporting context rather than causal proof.
Important interpretation rule: exact scheme dates are available and certain. Current output fields showing common or placeholder dates should be treated as the date used in that output run, not as evidence that exact dates are unavailable. Final analysis should keep the exact confirmed dates consistent across all reruns.

2. Data Preparation and Integrity

This section prepares the Vivacity data so later comparisons are not based on incomplete days, invalid records, or mixed outcome definitions.

  • Integrity gate: screens records for usable observations before descriptive or modelling analysis.
  • Full-day cutoff: applies count completeness rules so daily/weekly outputs are less affected by partial collection.
  • Modelling-ready inputs: creates analysis-ready datasets with intervention fields, outcomes, roles, and control matching variables.
  • Scheme dates: exact dates are available and should remain the final authoritative dates across all outputs.

5. Modelling Diagnostics and Current Limitations

This section tests whether the current data structure can support stronger causal claims. The present evidence is better described as descriptive and exploratory unless additional design improvements are made.

Causal Diagnostics

Checks whether treated and candidate control series have sufficient pre-period comparability for causal analysis.

causal_diagnostics_report_vivacity.docx

Exploratory Models

Explores model relationships and the current weakness of control-variable relationships.

vivacity_exploratory_models.Rmd

Methods Report

Documents current exploratory methods and interpretation constraints.

methods_vivacity_exploratory_analysis.docx

What remains weak

  • Some control relationships are weak, limiting confidence in causal estimates.
  • 12b and 12e cannot support a standard before/after comparison under the current quality-filtered baseline rules.
  • Weather, public holidays, seasonality, daylight, and event effects are not yet fully added as explanatory controls.
  • Non-intervention areas exist as candidates, but the final design needs a clear rule for when a control is valid versus descriptive-only.

8. Recommended Next Actions

  1. Preserve the confirmed scheme dates: treat the exact installation dates already used in the analysis as fixed inputs in every future rerun.
  2. Keep 12b and 12e wording precise: say pre-installation rows exist, but no usable positive pre-installation active-travel baseline remains after quality filtering.
  3. Separate outcomes consistently: continue reporting pedestrian, cyclist, active-travel total, road, and path/cycle-facility outputs separately.
  4. Strengthen the remaining model design: weather controls are now included; next add holidays/events where feasible and improve non-intervention comparison areas before making stronger causal claims.
  5. Use rail context only as context: report ORR station usage as background movement context, with explicit notes on the 2008/09 methodology break and 2003/04 missing data.
  6. Update presentation and draft wording: report that ERA5 adjustment changes the active-travel estimates by less than one percentage point and does not alter the interpretation.
