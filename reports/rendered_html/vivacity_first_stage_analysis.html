Purpose

This notebook is the first analysis stage after data cleaning and spatial/context joining.

It starts from the joined daily Vivacity + LSOA 2021 context table and produces:

  • deprivation groups using IMD deciles;
  • scheme and sensor readiness tables;
  • weekly and monthly descriptive summaries;
  • descriptive pre/post change tables;
  • exploratory interrupted time-series model tables for schemes with reliable pre/post data;
  • first dissertation plots for trends by scheme, route type, and deprivation group.

The analysis remains exploratory because matched non-intervention sensors have not yet been added. Therefore, the ITS outputs should be treated as early evidence of trajectories, not final causal estimates.

How To Use These Outputs

Use scheme_analysis_readiness.csv to decide which schemes are suitable for pre/post modelling. At present:

  • schemes with enough reliable pre/post data can enter exploratory ITS;
  • schemes with only post-installation data should be described as post-opening trajectories;
  • none of these should yet be treated as full causal estimates until matched non-intervention sensors are added.

Use pre_post_daily_mean_change_by_scheme_route.csv as a descriptive table for reporting early changes in average daily walking/cycling counts.

Use exploratory_its_key_terms.csv to report model direction and uncertainty. The most important ITS terms are:

  • post: immediate level change after the intervention month;
  • week_after: change in weekly trend after the intervention month.

Next Analysis Extension

The next methodological step is to add matched non-intervention countlines or areas. Once those are available, this notebook can be extended from single-series ITS to a controlled interrupted time-series or difference-in-differences design.
